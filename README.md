# Pseudoclases de CSS

Trabajo con ejemplos de las pseudoclases de CSS. Cada una tiene su demo en la pagina y su codigo comentado en `styles.css`.

## Archivos

- `index.html`: la maqueta con los ejemplos
- `styles.css`: los estilos
- `README.md`: este archivo

## Como verlo

Abrir `index.html` en el navegador (Chrome, Edge o Firefox actualizados).

## Pseudoclases incluidas

**Enlaces:** `:link`, `:visited`, `:any-link`, `:target`

**Interaccion:** `:hover`, `:active`, `:focus`, `:focus-visible`, `:focus-within`

**Formularios:** `:enabled`, `:disabled`, `:read-only`, `:read-write`, `:placeholder-shown`, `:default`, `:checked`, `:indeterminate`, `:required`, `:optional`, `:valid`, `:invalid`, `:in-range`, `:out-of-range`

**Estructura:** `:root`, `:empty`, `:first-child`, `:last-child`, `:only-child`, `:nth-child()`, `:nth-last-child()`, `:first-of-type`, `:last-of-type`, `:only-of-type`, `:nth-of-type()`, `:nth-last-of-type()`

**Funcionales:** `:not()`, `:is()`, `:where()`, `:has()`

**Idioma y direccion:** `:lang()`, `:dir()`

**Otros:** `:open`
